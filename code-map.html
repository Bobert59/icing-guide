Every module in the icing package, grouped by the job it does, with its size in lines and the guide page that explains it. Use the filter box to find a module or a word.

How to use this map

Start from an orchestrator (the first table) and follow the calls downward. The groups below follow the order of the icing loop. Line counts are from main on 17 November 2026 (about 21,800 lines in 134 files). Roles come from each module's docstring and public functions.

Outside the package

  • tests/: the unit-test suite (run with python -m unittest discover -s tests).
  • tools/: about 90 scripts that verify a model against an analytical case (verify_*), compare with data (compare_*), prepare user-run packages (prepare_*) or replay a saved state (replay_*).
  • hpc/nibi/: install, preflight and self-resubmitting job scripts for the Nibi cluster.
  • docs/: model descriptions, the physics review log and run returns. docs/MODELS.md and docs/PHYSICS_REVIEW.md are the best next reads after this guide.
