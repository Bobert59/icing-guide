SU2 icing research framework

How the icing solver works

A guided tour of the two-dimensional aircraft icing solver in this repository, from the physics of a supercooled droplet to the code that refines a mesh around a growing ice horn. Every figure is drawn from the solver's own code or from real saved runs.

How to read this guide

The pages follow one trip round the solver's loop, in the order the code runs it. Each page starts with the idea in plain words (Basic). It then explains how the solver does it (Intermediate) and ends with the equations, code excerpts and edge cases (Advanced). On a first pass, read the basic sections of every page. Then come back for the deeper sections.

Four kinds of boxes recur:

About this guide

Written on 17 November 2026 from the code on main (latest commit dc24dd2) and the saved runs in runs/. The code changes quickly. When a detail here disagrees with the source or with docs/, trust the source. The figure scripts are in _build/ and can be rerun to refresh the figures.
