# Icing Solver Guide

A static website that explains how the icing solver works, from the basic
physics to the code. Fifteen pages: a high-level overview, then one page per
stage (airflow, droplets, thermodynamics, film, conducting solid, ice growth,
meshing, glaze, multi-shot campaigns, validation), a code map and a glossary.

Published with GitHub Pages: https://bobert59.github.io/icing-guide/

The pages are plain HTML. To preview locally:

```
python -m http.server 8765
```

then open http://localhost:8765/.

The results shown are research results and are not validated predictions.
